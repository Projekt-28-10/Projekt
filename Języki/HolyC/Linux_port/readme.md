Jako że język programowania HolyC jest obsługiwany wyłącznie przez system operacyjny TempleOS, nie było możliwości skompilowania kodu bezpośrednio do pliku wykonywalnego dla systemu Linux. Oryginalny kod źródłowy (sito.HC) został uruchomiony w maszynie wirtualnej TempleOS. Aby umożliwić uruchomienie algorytmu na Linuksie bez maszyny wirtualnej, przygotowałem port, który za pomocą dyrektyw #define mapuje wbudowane funkcje i typy HolyC (np. Print, MAlloc) na ich odpowiedniki z języka C. Dzięki temu ten sam algorytm działa natywnie na Linuksie.
